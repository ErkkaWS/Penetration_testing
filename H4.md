<h2>H) File path traversal, traversal sequences stripped non-recursively</h2>

Jahas....eli melkein sama homma mutta tällä kertaa rikotaan ../ tiedostopolku komennot tuuttaamalla niitä monta kertaa peräkkäin. Jos ymmärsin oikein tällöin kierretään ../ merkkijonojen putsaus koska se suoriutuu sovelluksen puolella vain kerran. Eli tarkoituksena on tuutata suhteellista tiedostopolkukomentoa monta kertaa putkeen:

    ../../../etc/passwd 
komento ei menisi läpi koska `../` merkkijono putsataan syötteestä pois eli tällöin se ei menisi perille.
  
    ....//....//....//etc/passwd
tiedostopolku komennosta poistetaan kaikki `../`

    ..[../]/..[../]/..[../]/etc/passwd
[]sulkeissa olevat menevät poistoon yhden kerran jossa on se haavoittuvuus, jolloin URL syötteeseen jää:

    ../../../etc/passwd = juuri se komento mitä halutaan käyttää
