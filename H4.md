<h1>Tiivistelmät</h1>

<h3><a href="https://top10.owasp.org/2021/A01_2021-Broken_Access_Control/">OWASP TOP 10: 2021 - Broken Access Control</a></h3>
<ul>
  <li>Broken Access Control:</li>
  <li>tarkoitetaan haavoittuvuutta, jossa sovelluksissa hyödynnetään pääsynhallinnan puutetta,virhettä tai haavoittuvuutta: </li>
    <li>Rikkomalla "Least Privilige"- rikkeet, hankitaan pääsy paikkoihin jonne normaalisti pääsy rajattua</li>
    <li>Pääsynhallinta tarkistusten ohittamaninen muokkaamalla: URL:ia, muokkaamalla HTML- formaattia, muokkaamalla/käyttämällä API-pyyntöjä tai olemassa olevien tunnusten oikeuksien muuttaminen/korottaminen</li>
    <li>Keksien ja metadatatietojen manipulointi</li>
  <li>Miten estää?</li>
    <li>Deny by default - sovelluksessa lähtökohtaisesti kaikki pääsy muualle estetty</li>
    <li>Pääsynhallinta suoritettava palvelin puolella</li>
    <li></li>
</ul>

<h3>PortSwigger Acedemy</h3>
<ul>
  <li><a href="https://portswigger.net/web-security/access-control/idor">Insecure direct object references (IDOR)</a></li>
    <li>Hyökkäys/haavoittuvuus, jossa hyödynnetään sovelluksen heikkoja käyttäjien hallitsemia syötteitä, parametrejä tai olioita</li>
    <li>Pystyy muokkaamaan/hallitsemaan eri syötteitä, parametrejä tai olioita, jotka saattavat paljastaa dataa</li>
    <li>Esimerkiksi:</li>
    <li>muokkaamalla verkkoselaimen osoitekentässä paljastunutta tunnistetietoa:</li>

        https://insecure-website.com/customer_account?customer_number=132355 
  <li> muuttamalla tunnistetieto osoitekentästä: customer_number=132356, saattaa paljastaa toisen asiakkaan tiedot</li>    
  
  <li><a href="https://portswigger.net/web-security/file-path-traversal">Path traversal</a></li>
    <li>Path traversal/Directory traversal; Hyökkäys/haavoittuvuus, jossa hyödynnetään heikon sovelluksen käyttäjien hallitsemaa syötettä käyttämällä polkumerkintöjä, tarkoituksena; lukea, muokata, kirjoittaa tai hankkia pääsy host ympäristön alkuperäisestä hakemistossa tai sen ulkopuolelle/yläpuolelle </li>
  <li><a href="https://portswigger.net/web-security/cross-site-scripting">Cross-site scripting</a></li>
    <li>Cross-site scripting; Hyökkäys/haavoittuvuus jossa heikkoon sovellukseen pyritään syöttämään haitallista koodia, tavoitteena kaapata client istunto ja suorittamaan haitallisia toimintoja clientin nimissä</li>
</ul>
